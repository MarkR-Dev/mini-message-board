# mini-message-board

This is a basic message board app to practice using Node.js using the Express framework.

Topics practiced:

- Intro to the backend
- View (Templating via EJS)
- Controllers
- Routers
- Middleware
- Custom error handlers

This project was later expanded upon to practice:

- Using a database to store user messages (postgresql)
- Deploying using a hosting provider with a database
- Using express-validator to safely process/validate user input on the server side

Topics to research or improve on in the future:

- How to format date values inside a database
- Better naming conventions between variables used in server and database
- Cleaner and more readable code in routers
- Research into more appropriate validation methods for certain data inputs
